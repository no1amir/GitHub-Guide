# راهنمای Git و GitHub برای دانشجویان

این پروژه یک مستند آموزشی با عنوان «راهنمای Git و GitHub برای دانشجویان» است که برای درس مهندسی نرم‌افزار تهیه شده است. هدف آن آشنایی دانشجویانی است که تجربهٔ کمی در کار تیمی و کنترل نسخه دارند با Git و GitHub؛ به‌طوری که پس از مطالعه بتوانند یک پروژهٔ نرم‌افزاری را به‌صورت انفرادی یا گروهی مدیریت کنند و تغییرات خود را با اعضای تیم به اشتراک بگذارند.
